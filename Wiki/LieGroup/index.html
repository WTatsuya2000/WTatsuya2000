    Lie 群・表現論 公式集（SU(N) と格子計算向け）

    主な出典:

    • H. Georgi, Lie Algebras in Particle Physics, 2nd ed. (Westview, 1999)
    • R. Slansky, "Group theory for unified model building", Phys. Rept. 79, 1 (1981)（分岐則・次元の表）
    • M. Creutz, Quarks, Gluons and Lattices (Cambridge, 1983), Chap. 8（Haar 測度と群積分）
    • I. Montvay and G. Münster, Quantum Fields on a Lattice (Cambridge, 1994), Chap. 3
    • M. E. Peskin and D. V. Schroeder, An Introduction to QFT (1995), §15.4, Appendix A.3
    • L.-F. Li, "Group theory of the spontaneously broken gauge symmetries", Phys. Rev. D 9, 1723 (1974)（随伴 Higgs の対称性の破れ）

    \(SU(N)\) 全般 → \(SU(2)\), \(SU(3)\), \(SU(5)\) の具体形 → Young 図とテンソル積 → 随伴表現と随伴 Higgs → Haar 測度と群積分 → 強結合展開、の順に並べる。 Peskin 公式集 の A.3（群論）と重なる部分は同じ規約で書く。

    規約の要点

    • 生成子は Hermite、\(\mathrm{tr}(t^a t^b) = \tfrac12\delta^{ab}\)（基本表現）。物理の標準で、Peskin と同じ。数学の文献は反 Hermite \(X^a = -it^a\) を使うことが多い
    • 群元は \(U = \exp(i\theta^a t^a)\)。\(U = \exp(\theta^a X^a)\) と書く文献では \(\theta\) の符号が変わる
    • 随伴表現の生成子は \((T^a_A)_{bc} = -if^{abc}\)。\(\mathrm{tr}(T^a_A T^b_A) = N\delta^{ab}\)
    • Haar 測度は \(\int dU = 1\) に規格化する
    • Young 図の行の長さを \(\lambda = (\lambda_1 \ge \lambda_2 \ge \cdots)\)、Dynkin ラベルを \([a_1, \ldots, a_{N-1}]\)（\(a_i = \lambda_i - \lambda_{i+1}\)）と書く。\(\bar{r}\) は複素共役表現

    1. \(SU(N)\) の一般公式

    定義と構造定数

    \[ U^\dagger U = \mathbf{1}, \qquad \det U = 1, \qquad U = \exp(i\theta^a t^a), \qquad a = 1, \ldots, N^2 - 1 \]
    \[ (t^a)^\dagger = t^a, \qquad \mathrm{tr}\,t^a = 0, \qquad \mathrm{tr}(t^a t^b) = \tfrac12\delta^{ab}, \qquad [t^a, t^b] = if^{abc}t^c, \qquad \{t^a, t^b\} = \frac1N\delta^{ab}\mathbf{1} + d^{abc}t^c \]
    \[ t^a t^b = \frac{1}{2N}\delta^{ab}\mathbf{1} + \frac12\bigl(d^{abc} + if^{abc}\bigr)t^c, \qquad f^{abc} = -2i\,\mathrm{tr}\bigl([t^a, t^b]t^c\bigr), \qquad d^{abc} = 2\,\mathrm{tr}\bigl(\{t^a, t^b\}t^c\bigr) \]

    \(f^{abc}\) は完全反対称、\(d^{abc}\) は完全対称。\(SU(2)\) では \(d^{abc} = 0\)。Jacobi 恒等式:

    \[ f^{abe}f^{ecd} + f^{bce}f^{ead} + f^{cae}f^{ebd} = 0 \]

    一般化 Gell-Mann 基底

    \(N^2 - 1\) 個の生成子を、対称型 \(\tfrac12(E_{jk} + E_{kj})\)、反対称型 \(-\tfrac{i}{2}(E_{jk} - E_{kj})\)（\(j < k\)、\(E_{jk}\) は \((j,k)\) 成分だけ 1 の行列）と、対角型 \(N - 1\) 個で作る:

    \[ t^{(k)} = \frac{1}{\sqrt{2k(k+1)}}\,\mathrm{diag}(\underbrace{1, \ldots, 1}_{k}, -k, 0, \ldots, 0), \qquad k = 1, \ldots, N - 1 \]

    いずれも \(\mathrm{tr}(t^a t^b) = \tfrac12\delta^{ab}\) を満たす。

    縮約公式（Fierz 型）

    \[ (t^a)_{ij}(t^a)_{kl} = \frac12\Bigl(\delta_{il}\delta_{kj} - \frac1N\delta_{ij}\delta_{kl}\Bigr) \]
    \[ t^a t^a = C_F\mathbf{1} = \frac{N^2 - 1}{2N}\mathbf{1}, \qquad t^a t^b t^a = -\frac{1}{2N}t^b, \qquad t^a\,M\,t^a = \frac12\mathrm{tr}(M)\mathbf{1} - \frac{1}{2N}M \]
    \[ \mathrm{tr}(t^a t^b t^c) = \frac14\bigl(d^{abc} + if^{abc}\bigr), \qquad \mathrm{tr}(t^a t^b t^a t^c) = -\frac{1}{4N}\delta^{bc}, \qquad \mathrm{tr}(t^a t^b)\,\mathrm{tr}(t^a t^c) = \frac14\delta^{bc} \]
    \[ f^{acd}f^{bcd} = N\delta^{ab}, \qquad d^{acd}d^{bcd} = \frac{N^2 - 4}{N}\delta^{ab}, \qquad f^{acd}d^{bcd} = 0 \]
    \[ f^{abc}t^b t^c = \frac{i}{2}N t^a, \qquad d^{abc}t^b t^c = \frac{N^2 - 4}{2N}t^a \]
    \[ f^{abe}f^{cde} = \frac2N\bigl(\delta^{ac}\delta^{bd} - \delta^{ad}\delta^{bc}\bigr) + d^{ace}d^{bde} - d^{ade}d^{bce} \]

    Casimir 演算子と Dynkin 指数

    表現 \(r\)（次元 \(d(r)\)、生成子 \(T^a_r\)）に対して

    \[ T^a_r T^a_r = C_2(r)\mathbf{1}, \qquad \mathrm{tr}(T^a_r T^b_r) = T(r)\delta^{ab}, \qquad T(r)\,(N^2 - 1) = C_2(r)\,d(r) \]

    Peskin の記法では \(C(r) = T(r)\)。基本表現 \(F\) と随伴表現 \(A\):

    \[ C_2(F) = C_F = \frac{N^2 - 1}{2N}, \qquad T(F) = \frac12, \qquad C_2(A) = C_A = N, \qquad T(A) = N \]

    Young 図 \(\lambda\)（箱の総数 \(n = \sum_i\lambda_i\)、列の長さ \(\lambda^T_j\)）で指定した既約表現の 2 次 Casimir:

    \[ C_2(\lambda) = \frac12\Bigl[\,nN + \sum_i\lambda_i^2 - \sum_j(\lambda^T_j)^2 - \frac{n^2}{N}\Bigr] \]

    代表的な表現:

    表現 Young 図 \(d(r)\) \(C_2(r)\) \(T(r)\)
    基本 \(N\) \((1)\) \(N\) \(\dfrac{N^2-1}{2N}\) \(\dfrac12\)
    対称 2 階 \((2)\) \(\dfrac{N(N+1)}{2}\) \(\dfrac{(N-1)(N+2)}{N}\) \(\dfrac{N+2}{2}\)
    反対称 2 階 \((1,1)\) \(\dfrac{N(N-1)}{2}\) \(\dfrac{(N+1)(N-2)}{N}\) \(\dfrac{N-2}{2}\)
    随伴 \((2,1^{N-2})\) \(N^2 - 1\) \(N\) \(N\)

    Casimir スケーリング（弦張力の比）: \(\sigma_r/\sigma_F \approx C_2(r)/C_2(F)\)。随伴では \(C_2(A)/C_2(F) = 2N^2/(N^2 - 1)\)（\(SU(2)\): \(8/3\)、\(SU(3)\): \(9/4\)、\(SU(5)\): \(25/12\)）。

    1 ループ \(\beta\) 関数の係数（参考）

    \[ \beta(g) = -\frac{g^3}{(4\pi)^2}b_0, \qquad b_0 = \frac{11}{3}C_2(G) - \frac43\sum_{\text{Dirac } f}T(r_f) - \frac13\sum_{\text{complex } s}T(r_s) - \frac16\sum_{\text{real } s}T(r_s) \]

    QCD（\(N_f\) 個の基本表現 Dirac フェルミオン）では \(b_0 = 11 - \tfrac23 N_f\)。

    中心と Polyakov ループ

    \[ Z_N = \{z\mathbf{1} \mid z^N = 1\}, \qquad z = e^{2\pi ik/N} \]

    \(N\) 重性（\(N\)-ality）\(k\) の表現は中心の元 \(z\) で \(z^k\) 倍になる。基本表現は \(k = 1\)、随伴は \(k = 0\)。 中心変換 \(U_4(\mathbf{x}, t_0) \to zU_4(\mathbf{x}, t_0)\) で Polyakov ループは \(L \to zL\)、随伴ループ \(\lvert\mathrm{tr}\,L\rvert^2 - 1\) は不変。

    2. \(SU(2)\)

    \[ t^a = \frac{\sigma^a}{2}, \qquad f^{abc} = \epsilon^{abc}, \qquad d^{abc} = 0, \qquad U = \exp\Bigl(i\theta\,\hat{\mathbf n}\cdot\frac{\boldsymbol\sigma}{2}\Bigr) = \cos\frac\theta2 + i\,\hat{\mathbf n}\cdot\boldsymbol\sigma\,\sin\frac\theta2 \]
    \[ U = a_0\mathbf{1} + i\,\mathbf{a}\cdot\boldsymbol\sigma, \qquad a_0^2 + \mathbf{a}^2 = 1, \qquad \mathrm{tr}\,U = 2a_0 = 2\cos\frac\theta2, \qquad U^\dagger = a_0 - i\,\mathbf{a}\cdot\boldsymbol\sigma \]

    \(SU(2)\) の基本表現は擬実: \(\sigma^2 U^*\sigma^2 = U\)、\(\bar 2 \cong 2\)。\(\epsilon_{ij}\) で添字を上げ下げできる。

    表現はスピン \(j = 0, \tfrac12, 1, \ldots\) で指定する:

    \[ d(j) = 2j + 1, \qquad C_2(j) = j(j + 1), \qquad T(j) = \frac{j(j+1)(2j+1)}{3}, \qquad j_1\otimes j_2 = \bigoplus_{J = \lvert j_1 - j_2\rvert}^{j_1 + j_2} J \]
    \[ 2\otimes 2 = 1\oplus 3, \qquad 2\otimes 3 = 2\oplus 4, \qquad 3\otimes 3 = 1\oplus 3\oplus 5 \]

    指標（固有値 \(e^{\pm i\theta/2}\)、\(0 \le \theta \le 2\pi\)）:

    \[ \chi_j(\theta) = \frac{\sin\bigl((2j+1)\theta/2\bigr)}{\sin(\theta/2)}, \qquad \chi_{1/2} = 2\cos\frac\theta2 = \mathrm{tr}\,U, \qquad \chi_1 = 4\cos^2\frac\theta2 - 1 = \lvert\mathrm{tr}\,U\rvert^2 - 1 \]

    Haar 測度（class 関数に対して）:

    \[ \int_{SU(2)}dU\,f(U) = \frac1\pi\int_0^{2\pi}d\theta\,\sin^2\frac\theta2\,f(\theta) = \frac{1}{\pi^2}\int d^4a\,\delta(a^2 - 1)\,f(a) \]

    3. \(SU(3)\)

    Gell-Mann 行列 \(\lambda^a = 2t^a\)

    \[ \lambda^1 = \begin{pmatrix} 0&1&0 \\ 1&0&0 \\ 0&0&0 \end{pmatrix}, \quad \lambda^2 = \begin{pmatrix} 0&-i&0 \\ i&0&0 \\ 0&0&0 \end{pmatrix}, \quad \lambda^3 = \begin{pmatrix} 1&0&0 \\ 0&-1&0 \\ 0&0&0 \end{pmatrix}, \quad \lambda^4 = \begin{pmatrix} 0&0&1 \\ 0&0&0 \\ 1&0&0 \end{pmatrix} \]
    \[ \lambda^5 = \begin{pmatrix} 0&0&-i \\ 0&0&0 \\ i&0&0 \end{pmatrix}, \quad \lambda^6 = \begin{pmatrix} 0&0&0 \\ 0&0&1 \\ 0&1&0 \end{pmatrix}, \quad \lambda^7 = \begin{pmatrix} 0&0&0 \\ 0&0&-i \\ 0&i&0 \end{pmatrix}, \quad \lambda^8 = \frac{1}{\sqrt3}\begin{pmatrix} 1&0&0 \\ 0&1&0 \\ 0&0&-2 \end{pmatrix} \]
    \[ \mathrm{tr}(\lambda^a\lambda^b) = 2\delta^{ab}, \qquad [\lambda^a, \lambda^b] = 2if^{abc}\lambda^c, \qquad \{\lambda^a, \lambda^b\} = \frac43\delta^{ab}\mathbf{1} + 2d^{abc}\lambda^c \]

    構造定数（0 でない独立成分）

    \[ f^{123} = 1, \qquad f^{147} = f^{246} = f^{257} = f^{345} = \frac12, \qquad f^{156} = f^{367} = -\frac12, \qquad f^{458} = f^{678} = \frac{\sqrt3}{2} \]
    \[ d^{118} = d^{228} = d^{338} = \frac{1}{\sqrt3}, \qquad d^{888} = -\frac{1}{\sqrt3}, \qquad d^{146} = d^{157} = d^{256} = d^{344} = d^{355} = \frac12 \]
    \[ d^{247} = d^{366} = d^{377} = -\frac12, \qquad d^{448} = d^{558} = d^{668} = d^{778} = -\frac{1}{2\sqrt3} \]

    表現

    Dynkin ラベル \((p, q)\)（上付き添字 \(p\) 個、下付き添字 \(q\) 個の対称テンソル）で

    \[ d(p,q) = \frac{(p+1)(q+1)(p+q+2)}{2}, \qquad C_2(p,q) = \frac{p^2 + q^2 + pq + 3p + 3q}{3}, \qquad \overline{(p,q)} = (q,p) \]
    表現 \((p,q)\) Young 図 \(C_2\) \(T\) \(N\) 重性
    \(3\) \((1,0)\) \((1)\) \(4/3\) \(1/2\) 1
    \(\bar 3\) \((0,1)\) \((1,1)\) \(4/3\) \(1/2\) 2
    \(6\) \((2,0)\) \((2)\) \(10/3\) \(5/2\) 2
    \(8\) \((1,1)\) \((2,1)\) \(3\) \(3\) 0
    \(10\) \((3,0)\) \((3)\) \(6\) \(15/2\) 0
    \(15\) \((2,1)\) \((3,1)\) \(16/3\) \(10\) 1
    \(27\) \((2,2)\) \((4,2)\) \(8\) \(27\) 0

    テンソル積:

    \[ 3\otimes 3 = \bar 3\oplus 6, \qquad 3\otimes\bar 3 = 1\oplus 8, \qquad 3\otimes 3\otimes 3 = 1\oplus 8\oplus 8\oplus 10 \]
    \[ 8\otimes 8 = 1\oplus 8\oplus 8\oplus 10\oplus\overline{10}\oplus 27, \qquad 3\otimes 8 = 3\oplus\bar 6\oplus 15, \qquad 6\otimes\bar 3 = 3\oplus 15 \]

    指標（固有値 \(e^{i\theta_1}, e^{i\theta_2}, e^{-i\theta_1 - i\theta_2}\)）:

    \[ \chi_3 = \mathrm{tr}\,U, \qquad \chi_{\bar 3} = \mathrm{tr}\,U^\dagger = (\mathrm{tr}\,U)^*, \qquad \chi_8 = \lvert\mathrm{tr}\,U\rvert^2 - 1 \]
    \[ \chi_6 = \frac12\bigl[(\mathrm{tr}\,U)^2 + \mathrm{tr}\,U^2\bigr], \qquad \chi_{(1,1)} = \frac12\bigl[(\mathrm{tr}\,U)^2 - \mathrm{tr}\,U^2\bigr] = \chi_{\bar 3} \]

    一般に \(\chi_{(2)} = \tfrac12[(\mathrm{tr}\,U)^2 + \mathrm{tr}\,U^2]\)、\(\chi_{(1,1)} = \tfrac12[(\mathrm{tr}\,U)^2 - \mathrm{tr}\,U^2]\) は \(SU(N)\) で成り立つ。\(SU(3)\) では \((1,1) = \bar 3\) なので \((\mathrm{tr}\,U)^* = \tfrac12[(\mathrm{tr}\,U)^2 - \mathrm{tr}\,U^2]\) という恒等式になる。

    4. \(SU(5)\) と随伴 Higgs

    表現

    表現 Dynkin Young 図 \(C_2\) \(T\) \(N\) 重性
    \(5\) \([1,0,0,0]\) \((1)\) \(12/5\) \(1/2\) 1
    \(10\) \([0,1,0,0]\) \((1,1)\) \(18/5\) \(3/2\) 2
    \(15\) \([2,0,0,0]\) \((2)\) \(28/5\) \(7/2\) 2
    \(24\) \([1,0,0,1]\) \((2,1,1,1)\) \(5\) \(5\) 0
    \(45\) \([0,1,0,1]\) \((2,2,1,1)\) \(32/5\) \(12\) 1
    \(50\) \([0,2,0,0]\) \((2,2)\) \(42/5\) \(35/2\) 4
    \(75\) \([0,1,1,0]\) \((2,2,1)\) \(8\) \(25\) 0

    \(45\) と \(50\) はどちらを \(\bar{\ }\) 付きと呼ぶかが文献で分かれる。本ページは \(\bar 5\otimes 10 = 5\oplus 45\)、\(10\otimes 10 \ni 50\) が成り立つように付けた（Slansky と同じ）。\(24\), \(75\) は自己共役。

    テンソル積:

    \[ 5\otimes 5 = 10\oplus 15, \qquad 5\otimes\bar 5 = 1\oplus 24, \qquad 5\otimes 10 = \overline{10}\oplus 40, \qquad \bar 5\otimes 10 = 5\oplus 45 \]
    \[ 10\otimes 10 = \bar 5\oplus\overline{45}\oplus 50, \qquad 5\otimes 24 = 5\oplus 45\oplus 70, \qquad 24\otimes 24 = 1\oplus 24\oplus 24\oplus 75\oplus 126\oplus\overline{126}\oplus 200 \]

    分岐則 \(SU(5)\supset SU(3)_c\times SU(2)_L\times U(1)_Y\)

    \(Y\) の規格化は \(Q = T_3 + Y\)。\(\bar 5\) に \((d^c, L)\)、\(10\) に \((Q, u^c, e^c)\) が入る。

    \[ 5 = (3, 1)_{-1/3}\oplus(1, 2)_{1/2}, \qquad \bar 5 = (\bar 3, 1)_{1/3}\oplus(1, 2)_{-1/2} \]
    \[ 10 = (3, 2)_{1/6}\oplus(\bar 3, 1)_{-2/3}\oplus(1, 1)_1, \qquad 24 = (8, 1)_0\oplus(1, 3)_0\oplus(1, 1)_0\oplus(3, 2)_{-5/6}\oplus(\bar 3, 2)_{5/6} \]

    \(24\) の \((3,2)_{-5/6}\oplus(\bar 3,2)_{5/6}\) が \(X, Y\) ボソン。\(U(1)_Y\) の生成子を \(SU(5)\) の規格化に合わせると

    \[ T_Y = \sqrt{\frac35}\,Y = \frac{1}{\sqrt{60}}\,\mathrm{diag}(-2,-2,-2,3,3), \qquad \sin^2\theta_W\big|_{\text{GUT}} = \frac38 \]

    分岐則 \(SU(5)\supset SU(4)\times U(1)\)

    \[ 5 = 4_1\oplus 1_{-4}, \qquad 10 = 6_2\oplus 4_{-3}, \qquad 24 = 15_0\oplus 1_0\oplus 4_5\oplus\bar 4_{-5} \]

    （\(U(1)\) 電荷は \(\mathrm{diag}(1,1,1,1,-4)\) で定義。）

    随伴 Higgs \(\Phi = \Phi^a t^a\)

    \[ \Phi^\dagger = \Phi, \qquad \mathrm{tr}\,\Phi = 0, \qquad \Phi\to U\Phi U^\dagger, \qquad \mathrm{tr}\,\Phi^2 = \frac12\Phi^a\Phi^a, \qquad D_\mu\Phi = \partial_\mu\Phi - ig[A_\mu, \Phi] \]

    独立な不変量は \(\mathrm{tr}\,\Phi^2, \mathrm{tr}\,\Phi^3, \ldots, \mathrm{tr}\,\Phi^N\) の \(N - 1\) 個。4 次までのポテンシャルは

    \[ V(\Phi) = \frac{m^2}{2}\mathrm{tr}\,\Phi^2 + \frac{c}{3}\mathrm{tr}\,\Phi^3 + \lambda_1(\mathrm{tr}\,\Phi^2)^2 + \lambda_2\,\mathrm{tr}\,\Phi^4 \]
    • \(SU(2)\): \(\mathrm{tr}\,\Phi^3 = 0\)、\(\mathrm{tr}\,\Phi^4 = \tfrac12(\mathrm{tr}\,\Phi^2)^2\)
    • \(SU(3)\): \(\mathrm{tr}\,\Phi^4 = \tfrac12(\mathrm{tr}\,\Phi^2)^2\)（トレースレス \(3\times3\) の恒等式）
    • \(N\ge4\): \((\mathrm{tr}\,\Phi^2)^2\) と \(\mathrm{tr}\,\Phi^4\) が独立

    \(SU(5)\) の真空（Li 1974）。\(\Phi\) を対角化して \(\Phi = v\,\mathrm{diag}(\phi_1, \ldots, \phi_5)\) とすると、\(\lambda_2 > 0\) なら \(\mathrm{tr}\,\Phi^4/(\mathrm{tr}\,\Phi^2)^2\) を最小にする配位、\(\lambda_2 < 0\) なら最大にする配位が選ばれる:

    真空 残る対称性 \(\mathrm{tr}\,\Phi^2\) \(\mathrm{tr}\,\Phi^3\) \(\mathrm{tr}\,\Phi^4\) \(\mathrm{tr}\,\Phi^4/(\mathrm{tr}\,\Phi^2)^2\)
    \(v\,\mathrm{diag}(2,2,2,-3,-3)\) \(SU(3)\times SU(2)\times U(1)\) \(30v^2\) \(-30v^3\) \(210v^4\) \(7/30\)
    \(v\,\mathrm{diag}(1,1,1,1,-4)\) \(SU(4)\times U(1)\) \(20v^2\) \(-60v^3\) \(260v^4\) \(13/20\)

    \(c = 0\) のとき \(\lambda_2 > 0\) で \(SU(3)\times SU(2)\times U(1)\)、\(\lambda_2 < 0\) で \(SU(4)\times U(1)\)。\(c \ne 0\) では境界が動く（\(\mathrm{tr}\,\Phi^3\) の符号は \(\Phi\to-\Phi\) で反転するので \(c\) の符号は真空の符号に吸収できる）。

    一般の \(SU(N)\) 随伴 Higgs の真空は \(\Phi \propto \mathrm{diag}(\underbrace{N-k, \ldots}_{k}, \underbrace{-k, \ldots}_{N-k})\) の形で、残る対称性は \(SU(k)\times SU(N-k)\times U(1)\)。\(\lambda_2 > 0\) では \(k = \lfloor N/2\rfloor\) に最も近い分割、\(\lambda_2 < 0\) では \(k = 1\) が選ばれる。

    5. Young 図とテンソル積

    次元（hook 公式）

    Young 図 \(\lambda\) の箱 \((i,j)\)（\(i\) 行 \(j\) 列）に対して

    \[ d_N(\lambda) = \prod_{(i,j)\in\lambda}\frac{N + j - i}{h(i,j)}, \qquad h(i,j) = (\lambda_i - j) + (\lambda^T_j - i) + 1 \]

    \(h(i,j)\) はその箱の右と下にある箱の数に 1 を足したもの。

    基本的な規則

    • 1 列 \(N\) 箱は 1 重項。1 列 \(k\) 箱は反対称 \(k\) 階テンソル、次元 \(\binom{N}{k}\)
    • 複素共役表現 \(\bar\lambda\): 各列を \(N\) 箱に補完した図（列の長さ \(N - \lambda^T_j\) を逆順に並べる）。\(\bar N = (1^{N-1})\)、随伴 \((2, 1^{N-2})\) は自己共役
    • \(N\) 重性 \(= n \bmod N\)。\(N\) 重性の異なる表現の積には 1 重項が現れない
    • \(\lambda\otimes\mu\) に 1 重項が含まれるのは \(\mu = \bar\lambda\) のときだけ（多重度 1）

    Littlewood–Richardson 則（\(\lambda\otimes\mu\)）

    1. \(\mu\) の 1 行目の箱に \(a\)、2 行目に \(b\)、… とラベルを付ける
    2. \(\lambda\) に \(a\) の箱を、同じ列に 2 個以上入らないように付け足す（各段階で Young 図であること）
    3. 次に \(b\) の箱を同様に付け足す。以降同じ
    4. できた図の右上から左下へ（各行を右から左、行は上から下に）ラベルを読み、どの途中段階でも \(a\) の数 \(\ge b\) の数 \(\ge c\) の数 … となるものだけ残す
    5. 長さ \(N\) の列は消す。長さ \(N\) を超える列を持つ図は捨てる

    例: \(SU(N)\) で \(N\otimes N = (2)\oplus(1,1)\)、\(N\otimes\bar N = 1\oplus A\)、\(A\otimes A = 1\oplus A\oplus A\oplus\cdots\)。

    対称群との対応（Schur–Weyl）

    \(n\) 階テンソル \(V^{\otimes n}\) は \(SU(N)\) の Young 図 \(\lambda\)（\(n\) 箱）と \(S_n\) の既約表現 \(\lambda\) の対で分解する:

    \[ V^{\otimes n} = \bigoplus_{\lambda\vdash n,\ \lambda^T_1\le N} V_\lambda\otimes S_\lambda, \qquad N^n = \sum_\lambda d_N(\lambda)\,\dim S_\lambda \]

    \(\dim S_\lambda = n!/\prod h(i,j)\)。例: \(N^3 = d(3)\cdot1 + d(2,1)\cdot2 + d(1,1,1)\cdot1\)。

    6. 随伴表現

    \[ (T^a_A)_{bc} = -if^{abc}, \qquad \mathrm{tr}(T^a_A T^b_A) = f^{acd}f^{bcd} = N\delta^{ab}, \qquad T^a_A T^a_A = N\mathbf{1} \]

    随伴表現の群元（実直交行列）:

    \[ U_A^{ab} = 2\,\mathrm{tr}\bigl(t^a U t^b U^\dagger\bigr), \qquad U\,t^b\,U^\dagger = t^a\,U_A^{ab}, \qquad U_A\in SO(N^2 - 1), \qquad \mathrm{tr}\,U_A = \lvert\mathrm{tr}\,U\rvert^2 - 1 \]

    随伴表現は実で、中心 \(Z_N\) を忘れる: \(SU(N)/Z_N\) の表現。随伴 Polyakov ループは中心対称性で不変。

    基本表現の生成子と随伴表現の関係:

    \[ [t^a, t^b] = if^{abc}t^c = t^c\,(T^a_A)_{cb}, \qquad U^\dagger t^a U = U_A^{ab}\,t^b \]

    7. Haar 測度と群積分

    定義

    \[ \int dU = 1, \qquad \int dU\,f(U) = \int dU\,f(VU) = \int dU\,f(UV) = \int dU\,f(U^\dagger) \quad (V\in SU(N)) \]

    Weyl 積分公式（class 関数）

    固有値 \(e^{i\theta_1}, \ldots, e^{i\theta_N}\)（\(\sum\theta_i = 0 \bmod 2\pi\)）に対して

    \[ \int_{SU(N)}dU\,f(U) = \frac{1}{N!}\int_{-\pi}^{\pi}\prod_{i=1}^{N}\frac{d\theta_i}{2\pi}\;2\pi\,\delta\Bigl(\sum_i\theta_i\Bigr)\prod_{i<j}\bigl\lvert e^{i\theta_i} - e^{i\theta_j}\bigr\rvert^2\,f(\theta) \]

    \(SU(2)\) では \(\theta_1 = -\theta_2 = \theta/2\) で第 2 節の形になる。\(SU(3)\) では \(\theta_3 = -\theta_1 - \theta_2\) として

    \[ \int_{SU(3)}dU\,f(U) = \frac{1}{6(2\pi)^2}\int d\theta_1 d\theta_2\,\prod_{i<j}\bigl\lvert e^{i\theta_i} - e^{i\theta_j}\bigr\rvert^2 f(\theta_1, \theta_2) \]

    指標の直交性

    \[ \int dU\,\chi_r(U)\,\chi_s(U)^* = \delta_{rs}, \qquad \int dU\,\chi_r(UV)\,\chi_s(U^\dagger W) = \frac{\delta_{rs}}{d_r}\chi_r(VW) \]
    \[ \int dU\,\chi_r(UVU^\dagger W) = \frac{1}{d_r}\chi_r(V)\chi_r(W), \qquad \int dU\,D_r(U)_{ij}\,D_s(U)^*_{kl} = \frac{\delta_{rs}}{d_r}\delta_{ik}\delta_{jl} \]

    \(\chi_r(U) = \mathrm{tr}\,D_r(U)\)。\(\chi_r(U^\dagger) = \chi_r(U)^* = \chi_{\bar r}(U)\)。

    行列要素の積分

    \[ \int dU\,U_{ij} = 0, \qquad \int dU\,U_{ij}\,U^*_{kl} = \frac1N\delta_{ik}\delta_{jl}, \qquad \int dU\,U_{ij}\,U^\dagger_{kl} = \frac1N\delta_{il}\delta_{jk} \]
    \[ \int dU\,U_{ij}\,U_{kl} = 0 \quad (N\ge3), \qquad \int_{SU(2)}dU\,U_{ij}\,U_{kl} = \frac12\epsilon_{ik}\epsilon_{jl} \]
    \[ \int_{SU(N)}dU\,U_{i_1 j_1}U_{i_2 j_2}\cdots U_{i_N j_N} = \frac{1}{N!}\epsilon_{i_1 i_2\cdots i_N}\epsilon_{j_1 j_2\cdots j_N}, \qquad \int_{SU(3)}dU\,U_{ij}U_{kl}U_{mn} = \frac16\epsilon_{ikm}\epsilon_{jln} \]

    4 個の積分（\(N\ge2\)）:

    \[ \begin{aligned} \int dU\,U_{i_1 j_1}U_{i_2 j_2}U^*_{k_1 l_1}U^*_{k_2 l_2} &= \frac{1}{N^2 - 1}\bigl(\delta_{i_1 k_1}\delta_{j_1 l_1}\delta_{i_2 k_2}\delta_{j_2 l_2} + \delta_{i_1 k_2}\delta_{j_1 l_2}\delta_{i_2 k_1}\delta_{j_2 l_1}\bigr) \\ &\quad - \frac{1}{N(N^2 - 1)}\bigl(\delta_{i_1 k_1}\delta_{j_1 l_2}\delta_{i_2 k_2}\delta_{j_2 l_1} + \delta_{i_1 k_2}\delta_{j_1 l_1}\delta_{i_2 k_1}\delta_{j_2 l_2}\bigr) \end{aligned} \]

    一般の \(\int dU\,U_{i_1 j_1}\cdots U_{i_n j_n}U^*_{k_1 l_1}\cdots U^*_{k_n l_n}\) は Weingarten 関数 \(\mathrm{Wg}(\sigma\tau^{-1}, N)\) で書ける（\(U(N)\) では \(n < N\) で厳密。\(SU(N)\) では \(\epsilon\) 項が加わる）。

    生成子の積分（随伴表現）

    \[ \int dU\,U_A^{ab} = 0, \qquad \int dU\,U_A^{ab}U_A^{cd} = \frac{1}{N^2 - 1}\delta^{ac}\delta^{bd}, \qquad \int dU\,\mathrm{tr}(t^a U t^b U^\dagger) = 0 \]

    トレースの積分（\(SU(3)\)、Polyakov ループの計算で使う）

    \(L = \mathrm{tr}\,U\) として

    被積分関数 \(\int dU\) 理由
    \(L\) \(0\) \(3\) に 1 重項なし
    \(\lvert L\rvert^2\) \(1\) \(3\otimes\bar 3 \ni 1\)
    \(L^2\) \(0\) \(3\otimes 3 = \bar 3\oplus 6\)
    \(L^3\) \(1\) \(3\otimes3\otimes3 \ni 1\)（\(\epsilon\) 縮約）
    \(L^2 L^*\) \(1\) \((\bar 3\oplus 6)\otimes\bar 3 \ni 1\)
    \(\lvert L\rvert^4\) \(2\) \(\sum_r m_r^2\)、\(3\otimes3 = \bar3\oplus 6\)
    \(\lvert L\rvert^6\) \(6\) \(3^{\otimes3} = 1\oplus8\oplus8\oplus10\)、\(1+4+1\)
    \(\mathrm{tr}\,U^2\) \(0\) \(\chi_6 - \chi_{\bar 3}\)
    \(\lvert L\rvert^2 - 1\) \(0\) 随伴指標
    \((\lvert L\rvert^2 - 1)^2\) \(1\) \(8\otimes 8\ni 1\)

    一般に \(\int dU\,\chi_{r_1}\cdots\chi_{r_k}\) は \(r_1\otimes\cdots\otimes r_k\) に含まれる 1 重項の数。\(\int dU\,\lvert\chi_r\rvert^2\lvert\chi_s\rvert^2 = \sum_t m_t(r\otimes s)^2\)。

    \(SU(2)\) では \(\int dU\,L^2 = 1\)、\(\int dU\,L^4 = 2\)、\(\int dU\,L^{2k} = C_k\)（Catalan 数 \(C_k = \binom{2k}{k}/(k+1)\)）。

    8. 強結合展開の道具

    指標展開

    Wilson 作用 \(S = \beta\sum_P\bigl[1 - \tfrac1N\mathrm{Re}\,\mathrm{tr}\,U_P\bigr]\)、\(\beta = 2N/g^2\)。プラケット因子を指標で展開する:

    \[ \exp\Bigl[\frac\beta N\mathrm{Re}\,\mathrm{tr}\,U\Bigr] = \sum_r c_r(\beta)\,\chi_r(U), \qquad c_r(\beta) = \int dU\,\exp\Bigl[\frac\beta N\mathrm{Re}\,\mathrm{tr}\,U\Bigr]\chi_r(U)^* \]
    \[ c_0 = 1 + \frac{\beta^2}{4N^2} + \mathcal{O}(\beta^4), \qquad c_F = c_{\bar F} = \frac{\beta}{2N} + \mathcal{O}(\beta^3), \qquad \frac{c_F}{c_0} = \frac{\beta}{2N} + \mathcal{O}(\beta^3) \]

    \(SU(2)\) では厳密に

    \[ \exp\Bigl[\frac\beta2\mathrm{tr}\,U\Bigr] = \sum_{j=0,\frac12,1,\ldots}\frac{2(2j+1)}{\beta}I_{2j+1}(\beta)\,\chi_j(U), \qquad \frac{c_{1/2}}{c_0} = \frac{2I_2(\beta)}{I_1(\beta)} \xrightarrow{\beta\to0} \frac\beta4 \]

    \(I_n\) は変形 Bessel 関数。

    最低次の結果（\(SU(N)\)）

    \[ \Bigl\langle\frac1N\mathrm{Re}\,\mathrm{tr}\,U_P\Bigr\rangle = \frac{\beta}{2N^2} + \mathcal{O}(\beta^2), \qquad \langle W(R,T)\rangle = \Bigl(\frac{\beta}{2N^2}\Bigr)^{RT}\bigl[1 + \mathcal{O}(\beta)\bigr], \qquad \sigma a^2 = -\ln\frac{\beta}{2N^2} + \mathcal{O}(\beta) \]

    \(SU(3)\) では \(\sigma a^2 = -\ln(\beta/18)\)。\(SU(2)\) では \(-\ln(\beta/8)\)（正確には \(-\ln(I_2/I_1)\) の形で厳密に書ける）。

    リンク積分の基本形

    ある 1 本のリンク \(U\) が \(U\) と \(U^\dagger\) を 1 個ずつ含む場合:

    \[ \int dU\,\mathrm{tr}(AU)\,\mathrm{tr}(BU^\dagger) = \frac1N\mathrm{tr}(AB), \qquad \int dU\,\mathrm{tr}(AUBU^\dagger) = \frac1N\mathrm{tr}A\,\mathrm{tr}B \]

    \(SU(3)\) で \(U\) が 3 個並ぶ場合（バリオン型）:

    \[ \int dU\,\mathrm{tr}(AU)\,\mathrm{tr}(BU)\,\mathrm{tr}(CU) = \frac16\epsilon_{ikm}\epsilon_{jln}A_{ji}B_{lk}C_{nm} \]

    重クォークの Polyakov ループ

    Polyakov ループ \(L(\mathbf{x}) = \mathrm{tr}\prod_{t}U_4(\mathbf{x}, t)\) について、ゲージ場を積分すると

    \[ \int\prod dU_4\;L(\mathbf{x}) = 0, \qquad \int\prod dU_4\;L(\mathbf{x})L^*(\mathbf{y}) = \delta_{\mathbf{x}\mathbf{y}} + \mathcal{O}(\beta^{N_t\cdot\lvert\mathbf{x}-\mathbf{y}\rvert}), \qquad \int\prod dU_4\;L(\mathbf{x})^N = 1 \]

    最後の式が \(SU(N)\) の \(N\) クォーク（バリオン）状態に対応する。
