    Jackknife 法

    誤差推定の標準的な手法。複数のファイルに散らばっているコードをここに一本化する。

    完全版コード

    using Statistics

# ──────────────────────────────────────────────
# ブロック Jackknife の基本3関数
# ──────────────────────────────────────────────

"""
    BF(Ns, Nbin, NJK) -> UnitRange{Int}

全データ Ns 個を Nbin ブロックに分割したとき、
NJK 番目のブロックのインデックス範囲を返す。
"""
function BF(Ns::Int, Nbin::Int, NJK::Int)
    L     = div(Ns, Nbin)
    start = (NJK-1) * L + 1
    stop  = NJK * L
    return start:stop
end

"""
    BF_complement(Ns, Nbin, NJK) -> Vector{UnitRange{Int}}

NJK 番目のブロックを除いた残りのインデックス範囲を返す。
空のレンジは含まれない。
"""
function BF_complement(Ns::Int, Nbin::Int, NJK::Int)
    L  = div(Ns, Nbin)
    r1 = 1:((NJK-1)*L)
    r2 = (NJK*L+1):Ns
    return [r for r in (r1, r2) if !isempty(r)]
end

"""
    BF_mask(Ns, Nbin, NJK) -> BitVector

NJK 番目のブロックを false、それ以外を true とした
長さ Ns のマスクを返す。
"""
function BF_mask(Ns::Int, Nbin::Int, NJK::Int)
    mask = trues(Ns)
    mask[BF(Ns, Nbin, NJK)] .= false
    return mask
end

# ──────────────────────────────────────────────
# JK サンプルから平均・誤差を計算
# ──────────────────────────────────────────────

"""
    JackKnife(p0) -> (ave, err)

Nbin 個の JK サンプル p0 から平均と誤差を返す。
p0 が行列の場合は各列に対して計算する。
Nbin = length(p0)（または size(p0, 1)）を自動で使う。

使用例:
    Places = [fit_without_block(NJK) for NJK in 1:Nbin]  # Nbin × Nparam
    ave, err = JackKnife(hcat(Places...)')
"""
function JackKnife(p0)
    Nbin   = size(p0, 1)
    ave    = mean(p0, dims=1)
    nakami = sum(p0.^2, dims=1) / Nbin .- ave.^2
    err    = sqrt.((Nbin-1) .* nakami)
    return ave, err
end

    使い方

    典型的な JK ループ

    Nbin = 20
results = zeros(Nbin, Nparam)   # JK サンプルを格納

for NJK in 1:Nbin
    # NJK 番目のブロックを除いたデータでフィット
    mask = BF_mask(Nsamp, Nbin, NJK)
    results[NJK, :] = fit(data[mask, :])
end

ave, err = JackKnife(results)
println("$(ave[1]) ± $(err[1])")

    BF_complement を使うパターン（データを vcat でつなぐ場合）

    for NJK in 1:Nbin
    idx = BF_complement(Nsamp, Nbin, NJK)
    sub_data = vcat([data[r, :] for r in idx]...)
    results[NJK, :] = fit(sub_data)
end

    シンプル版（leave-one-out）

    ブロック不要で小さいサンプルに使う。

    """
    jk_mean_err(v) -> (mean, err)

Delete-1 Jackknife。v の各要素を1つずつ除いて平均を計算し、
JK 誤差を返す。Nbin = N（leave-one-out）。
"""
function jk_mean_err(v)
    N = length(v)
    N < 2 && return mean(v), NaN
    m = mean(v)
    θ = [(sum(v) - v[i]) / (N-1) for i in 1:N]
    σ = sqrt((N-1)/N * sum((θ .- mean(θ)).^2))
    return m, σ
end

    バリアント比較

    関数 特徴 使いどころ
    JackKnife(p0) JK サンプル → (ave, err) ループで JK サンプルを作ってから呼ぶ
    jk_mean_err(v) 生データ → (ave, err)、leave-one-out 小サンプル、簡単な量
    JKerror(result, Nbin) JackKnife と同じ。Nbin を明示する版 JackKnife で代替可

    誤差伝播（JK サンプルで計算した量）

    JK サンプルで非線形な量を計算するときは、サンプルごとに計算してから JackKnife を呼ぶ。

    # 例: R = A / B の誤差
A_jk = [fit_A(NJK) for NJK in 1:Nbin]
B_jk = [fit_B(NJK) for NJK in 1:Nbin]
R_jk = A_jk ./ B_jk                    # 各 JK サンプルで比を計算

ave, err = JackKnife(R_jk)
