    Measurements.jl — 誤差付き数値

    手動の誤差伝播が一切不要になる。

    using Measurements

# 誤差付き数値を定義
x = 1.52 ± 0.03
y = 0.88 ± 0.02

# 演算すると誤差が自動伝播
println(x + y)    # 2.40 ± 0.036
println(x * y)    # 1.338 ± 0.040
println(exp(x))   # 4.57 ± 0.14
println(x^2)      # 2.31 ± 0.091

    現在のコード（Places[Ndata, :, :] で JK サンプルを持ち回して最後に JackKnife() するパターン）と組み合わせれば、フィッティング結果の後処理が大幅に楽になる。

    # 現在のコード（手動）
ave, err = JackKnife(results)
ratio = ave[1] / ave[2]
ratio_err = ratio * sqrt((err[1]/ave[1])^2 + (err[2]/ave[2])^2)  # 手で計算

# Measurements.jl を使うと
r1 = ave[1] ± err[1]
r2 = ave[2] ± err[2]
ratio = r1 / r2   # 誤差伝播が自動
println(ratio.val, ratio.err)

    ProgressMeter.jl — プログレスバー

    長い MCMC ループに入れるだけで残り時間が表示される。

    using ProgressMeter

# @showprogress をループの前に付けるだけ
@showprogress for step = 1:Nmeasure
    HeatBath_step!(config, params)
    observe!(data, config, step)
end
# Progress: 100%|████████████████████| 10000/10000  ETA: 0:00:00 ( 2.3 ms/it)

    Jackknife ループにも有効：

    @showprogress "JK sampling..." for NJK = 1:Nbin
    Places[:, NJK] = fit_without_block(NJK)
end

    DrWatson.jl — 実験管理

    パラメータセットに対応したファイル名生成と結果の保存が体系化できる。

    using DrWatson
@quickactivate   # プロジェクトルートを自動認識

# 現在のコード（手動）
path = "x$(Lx)b$(βInt)d$(ΔInt).dat"

# DrWatson を使うと
params = @dict Lx β Δ
path = datadir("sims", savename(params, "dat"))
# → "data/sims/Δ=0.5_Lx=32_β=5.888.dat"（辞書順で自動命名）

    produce_or_load で「計算済みならロード、未計算なら実行して保存」が1行：

    result, _ = produce_or_load(params, datadir("results")) do p
    run_simulation(p[:Lx], p[:β], p[:Δ])
end

    ForwardDiff.jl — 自動微分

    現在 autodiff=:finite（有限差分）を使っているが、自動微分にすると速く精度も上がる。

    using ForwardDiff, Optim

# 現在
result = optimize(x -> chi2(exp.(x)), log.(x0), BFGS(); autodiff=:finite)

# ForwardDiff を使う（gradient を自分で渡す）
g!(G, x) = ForwardDiff.gradient!(G, y -> chi2(exp.(y)), x)
result = optimize(x -> chi2(exp.(x)), g!, log.(x0), BFGS())

    複素数の微分（LYZ の解析関数の勾配など）には ComplexDiff.jl または手書きが必要な場合もあるが、実数パラメータのフィッティングには有効。

    LsqFit.jl — 最小二乗フィット

    FSS（有限サイズスケーリング）のような標準的なカーブフィットに便利。

    using LsqFit

# モデル関数（Binder / Lee-Yang のスケーリング関数など）
model(x, p) = p[1] .+ p[2] .* (x .- p[3]) .* x.^p[4]

# フィット
fit = curve_fit(model, βs, data, [1.0, 1.0, 5.89, 1.0])

# 結果取得
params  = coef(fit)         # フィットパラメータ
errors  = stderror(fit)     # 標準誤差
chi2    = sum(fit.resid.^2) # 残差の二乗和

    FFTW.jl — 自己相関・τ_int

    現在の τint 計算（sature_τint のループ）を高速化できる。

    using FFTW, Statistics

function integrated_autocorr(x)
    N    = length(x)
    x_c  = x .- mean(x)
    # FFT を使った自己相関関数
    f    = fft(x_c, 1)
    acf  = real(ifft(f .* conj.(f))) ./ (N * var(x))
    acf  = acf[1:N÷2]
    # 自己相関時間
    τint = 0.5 + sum(acf[2:end])
    return τint, acf
end

τ, acf = integrated_autocorr(plaquette_series)

    DataFrames.jl — 構造化データ管理

    現在 Dict{String, Matrix{Float64}} で管理しているデータを、列名付きで扱える。

    using DataFrames, CSV

# 結果を DataFrame で管理
df = DataFrame(
    L     = Int[],
    β     = Float64[],
    R21   = Float64[],
    R21_err = Float64[],
)

for Lx in Lxs, β in βs
    push!(df, (Lx, β, r, r_err))
end

# 条件でフィルタ
subset(df, :L => l -> l .== 64)

# CSV で保存・読み込み
CSV.write("results.csv", df)
df = CSV.read("results.csv", DataFrame)

    Revise.jl — コードの即時反映

    REPL や Jupyter で .jl ファイルを編集したとき、セッションを再起動せずに変更が反映される。

    # startup.jl（~/.julia/config/startup.jl）に書いておくと常に有効
using Revise

# その後、スクリプトを include すると編集が自動反映
includet("analysis.jl")  # include ではなく includet を使う

    PrettyTables.jl — テーブル出力

    フィッティング結果を見やすく表示できる。

data = hcat(Lxs, aves, errs)
pretty_table(data;
    header      = ["L", "R₂₁", "δR₂₁"],
    formatters  = ft_printf("%.6f", [2,3]),
    highlighters = hl_lt(0.01, crayon"red bold"),
)

    StatsBase.jl — 統計処理の強化

    weights を使った加重統計や histogram が便利。

    using StatsBase

# 加重平均・加重分散（error_propagation の代替）
w   = Weights(1 ./ err.^2)
avg = mean(values, w)
σ   = std(values, w)

# ヒストグラム（MCMC のオブザーバブル分布）
h = fit(Histogram, plaquette_data, nbins=50)

    Polynomials.jl — 多項式操作

    Taylor 展開や多項式フィットをするときに。

    using Polynomials

# 多項式フィット（Lee-Yang ゼロ付近の展開など）
p = fit(Polynomial, βs, data, 3)   # 3次多項式
println(p)                          # -0.5 + 1.2x + 0.3x² - 0.1x³

# 根（ゼロ点）を求める
roots(p)

# 微分・積分
derivative(p)
integrate(p)
