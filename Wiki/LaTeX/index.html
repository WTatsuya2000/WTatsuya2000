    IguanaTex

    PowerPointにLaTeXを導入するための方法。
    windowsならここから飛べるよ。
    Macだと日本語の方法がないので、以下でまとめる。

    brew を用いて 

    brew tap tsung-ju/iguanatexmac
brew install --cask --no-quarantine iguanatexmac latexit-metadata
    でインストール。
    https://github.com/Jonathan-LeRoux/IguanaTex/releases からアドインのためのファイルを入れる。(.zip)を選択

    .zipを開いて、そのファイルがある場所で、 

    mkdir -p ~/Library/Application\ Scripts/com.microsoft.Powerpoint
cp ./IguanaTex.scpt ~/Library/Application\ Scripts/com.microsoft.Powerpoint/IguanaTex.scpt
    と 
    sudo mkdir -p '/Library/Application Support/Microsoft/Office365/User Content.localized/Add-Ins.localized'
sudo cp ./libIguanaTexHelper.dylib '/Library/Application Support/Microsoft/Office365/User Content.localized/Add-Ins.localized/libIguanaTexHelper.dylib'
    を実行する。

    後はアドインを追加すればいけるはず。 (参考) 公式github

    LaTeX プリアンプルの説明

    1. ドキュメントクラスの設定

    \documentclass[titlepage]{ltjsarticle}
%\documentclass{ltjsbook}
    • ltjsarticle: LuaLaTeX用のクラスファイルで、標準のarticleに対応。titlepageオプションでタイトルページが専用のページとして作成される。
    • ltjsbook: 書籍形式の文書を作成する場合に使用（コメントアウト中）。

    2. 日本語の設定

    \usepackage{luatexja}
    • luatexja: LuaLaTeXで日本語を扱うためのパッケージ。

    3. 数式パッケージ

    \usepackage{amsmath,amsfonts}
\usepackage{bm}
\usepackage[thicklines]{cancel}
\usepackage{color}
\renewcommand{\CancelColor}{\color[rgb]{0.7,0,0}}
    • amsmath, amsfonts: 高度な数式機能を提供。
    • bm: 数式中の太字ベクトルをサポート。
    • cancel: 数式に取り消し線を引くためのパッケージ。
    • color: 色を扱うためのパッケージ。
    • \renewcommand{\CancelColor}{\color[rgb]{0.7,0,0}}: cancelパッケージで使用する取り消し線の色を暗めの赤に設定。

    4. 画像関連パッケージ

    \usepackage[luatex]{graphicx}
    • graphicx: 画像を挿入するためのパッケージ。[luatex]オプションでLuaLaTeX専用のドライバを指定。

    5. 箇条書きパッケージ

    \usepackage{ascmac,paralist,enumerate}
    • ascmac, paralist, enumerate: 番号付き箇条書きやボックス付きテキスト、コンパクトなリスト作成をサポート。

    6. 物理関連パッケージ

    \usepackage{physics2}
\usephysicsmodule{ab,ab.braket}
\usephysicsmodule{op.legacy}
    • physics2: 物理記法を簡略化するためのパッケージ。
    • \usephysicsmodule{ab, ab.braket}: abモジュールとブラケット記法を使用。
    • \usephysicsmodule{op.legacy}: レガシーオペレーターの記法をサポート。

    7. 微分演算子と単位

    \usepackage{derivative,siunitx}
    • derivative, siunitx: 微分演算子とSI単位系を簡単に扱うためのパッケージ。

    8. ハイパーリンク

    \usepackage{url}
    • url: URLを処理するためのパッケージ。

    9. 図描画用パッケージ

    \usepackage[compat=1.1.0]{tikz-feynhand}
\usepackage{tikz}
    • tikz-feynhand: Feynmanダイアグラムを描画するためのTikZ拡張パッケージ。
    • tikz: 一般的な図形描画用パッケージ。

    10. 式番号のリセット

    \numberwithin{equation}{section}
\makeatletter
\@addtoreset{equation}{section}
\@addtoreset{figure}{section}
\@addtoreset{table}{section}
\makeatother
    • \numberwithin{equation}{section}: 式番号をセクション単位でリセット。
    • \@addtoreset{equation}{section}: 式、図、表の番号をセクションごとにリセットする設定。

    11. ハイパーリンク設定

    \usepackage[%
 setpagesize=false,%
 bookmarks=true,%
 bookmarksdepth=tocdepth,%
 bookmarksnumbered=true,%
 colorlinks=false,%
 pdftitle={},%
 pdfsubject={},%
 pdfauthor={},%
 pdfkeywords={}%
]{hyperref}
    • hyperref: PDF内のリンクやブックマークを管理するパッケージ。
    • setpagesize=false: ページサイズ設定を無効にする。
    • bookmarks=true: ブックマークを作成。
    • bookmarksdepth=tocdepth: 目次の深さまでブックマークを作成。
    • bookmarksnumbered=true: ブックマークに番号を付与。
    • colorlinks=false: ハイパーリンクに色を付けない。
    • その他: PDFのメタデータ（タイトル、著者、キーワードなど）を設定。

    12. セクション番号のカスタマイズ

    \makeatletter
\renewcommand{\appendix}{\par
  \setcounter{section}{0}%
  \setcounter{subsection}{0}%
  \gdef\presectionname{\appendixname}%
  \gdef\postsectionname{}%
  \gdef\thesection{\presectionname\@Alph\c@section\postsectionname}%
  \gdef\thesubsection{\@Alph\c@section.\@arabic\c@subsection}%
  \renewcommand{\theequation}{\@Alph\c@section.\arabic{equation}}%
  \renewcommand{\thefigure}{\@Alph\c@section.\arabic{figure}}%
  \renewcommand{\thetable}{\@Alph\c@section.\arabic{table}}%
}
\makeatother
    • \appendix: 付録のセクション番号をアルファベットに変更し、式番号、図番号、表番号をリセット。

    13. 新しいコマンド

    \newcommand{\Slash}[1]{{\ooalign{\hfil/\hfil\crcr$#1$}}}
\newcommand{\nuclear}[3]{{}^{#1}_{#2}\textrm{#3}}
\newcommand{\evalue}[1]{\braket <{#1}>}
    • \Slash: 式に斜線を引くためのコマンド。
    • \nuclear: 核種を表記するためのコマンド。例: \nuclear{235}{92}{U} は \( ^{235}_{92} \textrm{U} \) と表示される。
    • \evalue: ブラケット記法を簡単に使うためのコマンド。

    14. BibTeX

    \bibliography{Bi} %hoge.bibから拡張子を外した名前
\bibliographystyle{junsrt} %参考文献出力スタイル
    この後に4回コンパイルする必要があるので、基本はoffにした方が良い。 
    {
              "name": "Paper(ja)",
              "tools": [
                  "lualatex(ja)",
                  "pbibtex(ja)",
                  "lualatex(ja)",
                  "lualatex(ja)"
              ]
          }
