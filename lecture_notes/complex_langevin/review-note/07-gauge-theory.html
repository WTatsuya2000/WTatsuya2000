複素ランジュバン法

目次

Seiler ほか 2013 / Nagata ほか 2016a / Attanasio と Jäger 2019 に対応 ゲージ理論への拡張

リンク変数のランジュバン方程式を書き、作用が複素数のときリンクが SU(N) から SL(N,C) へ出ていくことを見る。複素化したゲージ軌道が非コンパクトであることが不安定性の原因であり、それを抑えるゲージ冷却と動的安定化をまとめる。

リンク変数のランジュバン方程式

Definition
生成子 \(\lambda_a\) と左微分 \(D_a f(U) = \partial_\alpha f\bigl(e^{i\alpha\lambda_a}U\bigr)\big|_{\alpha=0}\) を用いて、離散化されたランジュバン更新を
\[ U_{x,\nu}(\theta+\epsilon) = \exp\Bigl[i\lambda_a\bigl(\epsilon K_{a,x\nu} + \sqrt{\epsilon}\,\eta_{a,x\nu}\bigr)\Bigr]\,U_{x,\nu}(\theta) \]
で定める。ドリフトは \(K_{a,x\nu} = -D_{a,x\nu}S\)、ノイズは \(\langle\eta\eta\rangle=2\delta\) とする。\(S\) が実なら \(K_a\) も実で、\(U\) は SU(\(N\)) に留まる。

複素化：SU(N) から SL(N,C) へ

\(S\) が複素数（有限 \(\mu\) の \(-\ln\det M\) を含む）だと \(K_a\in\mathbb C\) となり、更新行列 \(e^{i\lambda_aK_a}\) はユニタリでなくなる。 生成子がトレースレスなので \(\det U=1\) は保たれ、リンクは複素化された群 \(\SLNC\) を動く（演習 7.4）。これは 1 変数の \(x\to x+iy\) の自然な一般化である。

\(U^\dagger\) ではなく \(U^{-1}\) を使う Caution
作用と観測量は複素化したリンクの正則関数でなければならない。\(U^\dagger\) の成分は反正則なので、SU(\(N\)) 上で \(U^\dagger=U^{-1}\) であることを使い、 プラケット作用や Dirac 演算子の後ろ向きホッピング項は \(U^{-1}\) で書いてから解析接続する（演習 7.3）。
Definition
\[ d = \frac{1}{4\Omega}\sum_{x,\nu}\frac{1}{N}\tr\bigl(U_{x\nu}U_{x\nu}^\dagger - \mathbb 1\bigr)\ \ge 0 \]
（\(\Omega\) は格子点数）。\(d=0\) ⇔ 全リンクがユニタリ（演習 7.1）。\(\tr[(UU^\dagger-1)^2]\) 型の定義も使われる。

\(d\) が大きく育つと、第 5 章の意味で \(P\) の裾が重くなり、結果が信頼できなくなる。

なぜゲージ理論で特に難しいか

ゲージ変換 \(U_{x\nu}\to \Omega_x U_{x\nu}\Omega_{x+\hat\nu}^{-1}\) も複素化され、\(\Omega_x\in\SLNC\) となる。 SU(\(N\)) のゲージ軌道はコンパクトだが、\(\SLNC\) のゲージ軌道は非コンパクトで、ゲージ不変な作用はその方向にドリフトを与えない。 数値誤差や非可換性の効果でこの平坦な方向に配位が拡散すると、ユニタリティ・ノルムが際限なく増大する。

ゲージ冷却

各ランジュバンステップの後に、物理量（ゲージ不変量）を変えずにユニタリティ・ノルムを下げる \(\SLNC\) ゲージ変換を施す 。 その方向を、点 \(x\) だけでの変換に対する \(\sum\tr UU^\dagger\) の勾配から決める。

Derivation — 冷却の勾配
出発
ユニタリティ・ノルム のうち点 \(x\) に接するリンクの寄与
目標
冷却の勾配 \(G_{a,x}\)
方針
点 \(x\) で非ユニタリなゲージ変換 \(\Omega=e^{\alpha\lambda_a}\) を施し、\(\alpha=0\) で微分する

  1. 点 \(x\) から出るリンクと入るリンクを変換する

    \[ U_{x\nu}\to\Omega U_{x\nu},\qquad U_{x-\hat\nu,\nu}\to U_{x-\hat\nu,\nu}\Omega^{-1},\qquad \Omega=e^{\alpha\lambda_a},\ \alpha\in\mathbb R \]
    なぜ
    \(\lambda_a\) はエルミートなので \(\Omega^\dagger=\Omega\neq\Omega^{-1}\)（非ユニタリ）だが、\(\det\Omega=e^{\alpha\tr\lambda_a}=1\) で \(\SLNC\) に属する。SU(\(N\)) の変換ではノルムが変わらない（演習 7.2）。

  2. 出るリンクの寄与を \(\alpha\) で微分する

    \[ \tr(\Omega UU^\dagger\Omega^\dagger)=\tr(\Omega^2UU^\dagger)\ \Rightarrow\ \frac{d}{d\alpha}\Big|_0=2\tr(\lambda_aUU^\dagger) \]

  3. 入るリンクの寄与を \(\alpha\) で微分する

    \[ \tr(U\Omega^{-1}\Omega^{-1\dagger}U^\dagger)=\tr(\Omega^{-2}U^\dagger U)\ \Rightarrow\ \frac{d}{d\alpha}\Big|_0=-2\tr(\lambda_aU^\dagger U) \]

  4. 全ての方向 \(\nu\) について足し合わせる

    \[ G_{a,x} = 2\,\tr\Bigl[\lambda_a\sum_\nu\bigl(U_{x\nu}U_{x\nu}^\dagger - U_{x-\hat\nu,\nu}^\dagger U_{x-\hat\nu,\nu}\bigr)\Bigr] \]
Procedure
各ランジュバンステップの後に、最急降下の変換 \(\Omega_x = \exp(-\epsilon\,\alpha_{gc}\, G_{a,x}\lambda_a)\) を全格子点で何回か繰り返す。 ゲージ不変な観測量は変わらず、ユニタリティ・ノルムだけが下がる。
原論文に書かれていること In the paper
はゲージ冷却を導入して重いクォークの QCD の CL シミュレーションを安定化し、 再重み付けの結果と推定誤差の範囲で一致すること、以前は到達できなかった高いバリオン密度まで計算できることを報告している（arXiv の abstract による）。 ゲージ冷却を入れても正当化の議論が保たれることは で示されている。
注意・限界 Caution
冷却が有効なのは格子間隔が十分細かい（\(\beta\) が大きい）場合で、粗い格子では冷却しても配位を SU(\(N\)) 近傍に保てないことが報告されている。 具体的な閾値は作用やフェルミオンの種類によるので、原論文の図で確認すること。

動的安定化

ゲージ冷却を補うものとして、ランジュバンのドリフトに SU(\(N\)) 上では消える小さな非正則の項を加え、配位を SU(\(N\)) 方向に引き戻す方法が提案されている 。

\[ K_{a,x\nu}\;\to\;K_{a,x\nu} + i\,\alpha_{DS}\,M_{a,x} \]

\(M_{a,x}\) は \(b_{a,x} = \tr[\lambda_a\sum_\nu U_{x\nu}U_{x\nu}^\dagger]\) の高次のべきで構成され、SU(\(N\)) から離れると急速に大きくなる。

確認していない点 Caution
\(M_{a,x}\) の具体的な形と \(\alpha_{DS}\) の推奨値は、本ノートでは原論文の本文と照合していない。実装する場合は の定義を参照すること。
自分の解釈 My reading
正則性を破るので第 5 章の形式的正当化の外にある。それでも \(\alpha_{DS}\) 依存性が小さい領域で結果が安定することが数値的に示されており、 「正当化された手続き」というより「よく較正された経験則」として扱うのが妥当だと考える。
