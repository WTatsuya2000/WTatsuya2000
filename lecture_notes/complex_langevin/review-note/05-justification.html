複素ランジュバン法

目次

Aarts ほか 2010b, 2011 / Nagata ほか 2016b / Scherzer ほか 2019 に対応 正当化と収束の判定条件

CL が正しい期待値を与えることの形式的証明を補間関数で組み立て、それが部分積分の境界項でどう破れるかを見る。そのうえで、実際のシミュレーションで正しさを確かめる 3 つの判定法（整合性条件・境界項・ドリフト分布）をまとめる。

形式的な証明

正則な観測量 \(O(z)\) の時間発展を、ランジュバン演算子

\[ \tilde L = \bigl(\partial_z - S'(z)\bigr)\partial_z,\qquad \partial_\tau O(z;\tau) = \tilde L\,O(z;\tau) \]

で定める。正則関数に作用するときは \(\partial_x=\partial_z\)、\(\partial_y=i\partial_z\) なので \(N_R\partial_x^2+N_I\partial_y^2=(N_R-N_I)\partial_z^2=\partial_z^2\) となり、実 Fokker–Planck 演算子の随伴 \(L\) と \(\tilde L\) が一致する（演習 5.1）。

Derivation — 補間関数
出発
実の分布 \(P\) と複素の分布 \(\rho\) による 2 つの期待値
目標
両者の差が境界項だけで書けること
方針
\(P\) の時間発展と \(O\) の時間発展を時刻 \(\tau\) で受け渡す関数を作り、\(\tau\) で微分して部分積分する

  1. 補間関数 \(F(\theta,\tau)\) を定義する

    \[ F(\theta,\tau) = \int dx\,dy\; P(x,y;\theta-\tau)\, O(x+iy;\tau),\qquad 0\le\tau\le\theta \]

  2. 両端の値を読み取る

    \[ F(\theta,0)=\langle O\rangle_{P(\theta)},\qquad F(\theta,\theta)=O(x_0;\theta)=\langle O\rangle_{\rho(\theta)} \]
    なぜ
    初期条件を \(P(x,y;0)=\delta(x-x_0)\delta(y)\)、\(\rho(x;0)=\delta(x-x_0)\) にそろえる。\(O(z;\theta)=e^{\theta\tilde L}O\) は複素 Fokker–Planck 方程式の随伴発展なので、\(O(x_0;\theta)=\int\rho(x;\theta)O(x)dx\)。

  3. \(F\) を \(\tau\) で微分し、\(L^T P\) の項を部分積分で \(P\) の外へ移す

    \[ \partial_\tau F = -\int (L^T P)\, O + \int P\, (\tilde L O) = (\text{部分積分の表面項}) \]
    なぜ
    表面項がなければ \(\int(L^TP)O=\int P(LO)\)、正則な \(O\) に対し \(LO=\tilde LO\) なので 2 項は打ち消す。

  4. \(N_I=0\) のとき、\(y=\pm Y\) での表面項を具体的に書く

    \[ \partial_\tau F = \lim_{Y\to\infty}\int dx\,\Bigl[K_y\,P(x,y;\theta-\tau)\,O(x+iy;\tau)\Bigr]_{y=-Y}^{y=Y} \]
    なぜ
    \(x\) が周期的（コンパクト）なら \(x\) 方向の表面項は消える。導出の詳細は演習 5.4。ドリフトに極がある場合は、極を囲む小円上にも同様の表面項が現れる。
Result
境界項 が全ての \(0\le\tau\le\theta\) で消え、かつ \(\rho(x;\theta)\) が \(e^{-S}/Z\) に収束するなら、 正則な観測量に対して \(\langle O\rangle_{P(\theta\to\infty)} = \int O\,e^{-S}/Z\) が成り立つ。
原論文に書かれていること In the paper
は正しさの形式的な導出を与えたうえで、そのいくつかの数学的な抜け穴を指摘し、 簡単な例の研究から実用上の提案を行っている（arXiv の abstract による）。

抜け穴

形式的証明が破れる典型的な状況は次の 2 つである。

証明が破れる状況 Caution
  • 無限遠での裾：\(P(x,y)\) が \(|y|\to\infty\) で十分速く減衰しないと、\(O(z;\tau)\)（多くの場合 \(|y|\) について指数関数的に増える）との積の表面項が残る 。
  • ドリフトの極（特異ドリフト）：\(S=-\ln\det M+\cdots\) のように対数を含むと、\(\det M\) の零点で \(S'\) が極をもつ。極のまわりで \(P\) が十分速く 0 にならないと境界項が生じる 。

このほか、複素 Fokker–Planck 演算子のスペクトルが（\(e^{-S}\) 以外で）正の実部をもつ固有値をもたないこと、エルゴード性なども暗に仮定されている。 境界項・スペクトルとの関係の整理は を参照。

実用的な判定条件

整合性条件

定常状態で、任意の正則 \(O\) について

\[ \bigl\langle \tilde L O\bigr\rangle_P = \bigl\langle O''-S'O'\bigr\rangle_P = 0 \]

が成り立つことを確かめる 。これは厳密な期待値が満たす Schwinger–Dyson 方程式と同じものである（演習 5.2）。 全ての \(O\) を調べるのは不可能なので、いくつかの \(O\) での確認は必要条件にとどまる。

境界項の直接計算

カットオフ \(Y\) を入れて

\[ B_O(Y) = \bigl\langle \Theta(Y-|y|)\,\tilde L O\bigr\rangle_P \]

を測り、\(Y\to\infty\) で 0 に向かうかを見る 。格子模型への適用と、境界項から系統誤差を見積もる方法は にある。

ドリフトの分布

Criterion
ドリフトの大きさ \(u=|K|\) の確率分布 \(p(u)\) が、大きな \(u\) で指数関数的（またはそれ以上に速く）減衰していれば正しい結果が得られる。 冪的な裾 \(p(u)\sim u^{-\alpha}\) は危険信号である 。
